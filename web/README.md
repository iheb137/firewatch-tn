# Interface FireWatch TN (React)

Prévue au sprint « Interface » (semaines 4 à 8 du planning).

Stack retenue (cf. `docs/cadrage_firewatch_tn.pdf`, section 8) : React 19, TypeScript,
Vite, MapLibre GL JS et deck.gl pour la carte 3D, Tailwind CSS, shadcn/ui, Framer Motion,
Recharts, TanStack Query et Zustand.

L'interface consomme uniquement la passerelle `services/api`
(`http://localhost:8000/api/v1`, documentation interactive sur `/docs`).
